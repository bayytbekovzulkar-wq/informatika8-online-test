# Informatika 8 — Online Test

Образовательная веб-платформа для проведения онлайн-тестирования учеников 8-го класса по предмету **«Информатика»** (учебная программа: **Ибирайым кызы А., Н. Н. Осипова**).

Платформа разработана специально для инфраструктуры **Cloudflare** (бесплатный тариф):
- **Frontend**: React 18 + Vite 5 + адаптивный CSS3 (светлая сине-фиолетовая тема, 100% русский интерфейс).
- **Хостинг**: Cloudflare Pages.
- **Backend / API**: Cloudflare Pages Functions (Cloudflare Workers) в каталоге `/functions`.
- **База данных**: Cloudflare D1 (SQLite) с готовыми SQL-миграциями.
- **Защита от ботов**: опциональная интеграция Cloudflare Turnstile.

## Основные возможности

### Для учеников
- Вход без регистрации: **Имя**, **Фамилия** и **Код подключения класса** от учителя.
- Отображение только тестов своего класса со статусами (**Доступен**, **Завершён**, **Недоступен**).
- Живой таймер, привязанный к серверному времени, с автоматической отправкой по истечении времени.
- Два режима просмотра вопросов (**По одному** / **Все вопросы**), навигатор с выделением неотвеченных вопросов.
- Автосохранение промежуточных ответов в Cloudflare D1 и защита от случайного обновления или закрытия страницы.
- Правильные ответы и пояснения не передаются на клиент до завершения тестирования.

### Для учителя (`/teacher`)
- Защищённый вход по логину и паролю (хеширование PBKDF2-SHA256, подписанные HttpOnly cookies, тайм-аут сессии, смена пароля).
- **Главная панель**: количество учеников, тестов, попыток, средний балл, распределение оценок, успеваемость по темам, последние результаты.
- **Классы**: создание, переименование, удаление, генерация и обновление кодов подключения, просмотр учеников класса.
- **Ученики**: поиск по ФИО, фильтр по классу, история тестирований, выдача дополнительной попытки (пересдачи), удаление ошибочных записей.
- **Тесты и программа**: 4 готовые темы программы 8 класса с подтемами, конструктор и редактор тестов и практических заданий, все 5 типов вопросов (один ответ, несколько ответов, верно/неверно, число, текст), лимит попыток, расписание (дата начала/окончания), перемешивание вопросов и ответов.
- **Результаты**: фильтрация по классам, ученикам, темам, тестам, датам, сортировка по оценкам и процентам, экспорт в **CSV** и **Excel (.xls)**.
- **Настройки**: редактирование 5-балльной шкалы оценивания (по умолчанию 90/70/50%), управление публикацией оценок и пояснений ученикам, длительность сессии.

## Локальный запуск для разработки

```bash
# 1. Установите зависимости
npm install

# 2. Создайте локальный файл секретов
cp .env.example .dev.vars

# 3. Примените SQL-миграции к локальной базе D1
npm run db:migrate:local

# 4. Соберите фронтенд и запустите Cloudflare Pages + Workers локально
npm run build
npm run cf:dev
```

Откройте `http://127.0.0.1:8788` в браузере.
Для быстрого теста уже создан демонстрационный класс **8-А** с кодом подключения **`INFO8A`**.

Подробная инструкция по развёртыванию в облаке Cloudflare — в файле **`DEPLOY_CLOUDFLARE.md`**.
